Privacy Policy – NeverLate

NeverLate is a Chrome extension designed to help users avoid missing meetings by providing reminders based on their Google Calendar events.

Google User Data We Access

  • Google Calendar events (read-only access)

How Google User Data Is Used

Google Calendar data is used solely to:

  • Identify upcoming meetings
  • Determine meeting start times
  • Extract Google Meet links from calendar events
  • Trigger reminders and automatic meeting opening

Data Sharing and Disclosure

NeverLate does not share, transfer, disclose, or sell Google user data to any third parties.

Google user data is accessed only by the extension running locally in the user’s browser and is never transmitted to external servers.

Data Storage and Protection

NeverLate does not store Google Calendar data on any remote servers. Any user preferences or reminder settings are stored locally in the user’s browser using Chrome’s local storage mechanisms.

Access to Google data is protected through Google OAuth 2.0 authentication and standard browser security controls.

Data Retention and Deletion

NeverLate does not retain Google Calendar data beyond what is required for real-time reminder functionality.

Calendar data is accessed dynamically and discarded immediately after use. Users may revoke Google account access at any time via their Google Account permissions page, which immediately stops all data access.

Third-Party Services

NeverLate uses the Google Calendar API to access calendar events with user consent. No other third-party services or analytics tools are used.
