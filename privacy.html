Privacy Policy – NeverLate

NeverLate only accesses Google Calendar data to provide meeting reminders and automation. We do not sell, share, or use Google user data for advertising or marketing purposes.

Google User Data We Access

  • Calendar events (read-only, to generate reminders)

How Google User Data Is Used

Google Calendar data is used only to:

  • Identify upcoming meetings
  • Determine meeting start times
  • Extract Google Meet links from calendar events
  • Trigger reminders and automatically open meetings

Data Sharing and Disclosure

NeverLate does not share, transfer, disclose, or sell Google user data to any third parties.

Google user data is accessed only by the extension running locally in the user’s browser and is never transmitted to external servers.

Data Storage and Protection

NeverLate does not store Google Calendar data on any remote servers. User preferences and reminder settings are stored locally in the browser.

Access to Google user data is protected using Google OAuth 2.0 and standard browser security mechanisms.

Data Retention and Deletion

Google Calendar data is accessed only when needed for real-time functionality and is not retained after use.

Users can revoke access at any time from their Google Account permissions, which immediately stops all data access by the extension.

Third-Party Services

NeverLate uses the Google Calendar API to access calendar data with user consent. No other third-party services or analytics tools are used.
